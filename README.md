# 過酸化水素の分解速度ラボ

酸素の捕集記録から過酸化水素の濃度と平均減少速度を計算する、ブラウザー上の学習教材です。

公開サイト：https://peroxide-reaction-lab.nuttyden4.chatgpt.site

## 使い方

`dist/index.html` をブラウザーで開きます。インストールやビルドは不要です。

1. 実験条件で、初濃度の求め方、大気圧、反応液の体積、共通の測定温度を設定します。
2. 0分の初期体積と、各測定時刻の捕集体積を入力します。初期行に加えて測定用の5行を用意しています。
3. 各時刻の濃度とグラフを確認します。記録はブラウザーに保存され、CSVで書き出せます。

捕集体積は累積方式と区間方式を選べます。水上置換では水蒸気圧を補正します。温度は一定と仮定し、すべての行に共通の測定温度を使います。

## ファイル

- `dist/index.html`：画面と計算方法の説明
- `dist/style.css`：画面のデザイン
- `dist/app.js`：入力、表示、グラフ、保存、CSV出力
- `dist/calc.js`：気体の状態方程式、濃度と速度の計算、一次反応を仮定した回帰
- `tests/`：計算と画面処理の自動チェック（ブラウザー描画の確認は含みません）

## 計算方法

反応式：2 H₂O₂ → 2 H₂O + O₂

- 酸素量：n(O₂) = P(O₂)V / RT
- 濃度減少：D(t) = 2n(O₂) / 反応液の全体積(L)
- 残存濃度：C(t) = C₀ − D(t)

初濃度が不明な場合は、区間ごとの x = −(D前 + D後)/2、y = (D後 − D前)/Δt を用いて y = kx + b を回帰し、C₀ = b/k として推定します。有効な区間が3つ以上必要です。この推定は一次反応の仮定に依存します。

気体定数は添付Excelに合わせて R = 8.31、絶対温度への換算は ℃ + 273.15 です。温度の入力範囲は0〜60 ℃です。
