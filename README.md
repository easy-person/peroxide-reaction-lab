# 過酸化水素の分解速度ラボ

講座リンクからクラスを選び、班名・時間・酸素累積量・実験温度を入力して保存する学習教材です。保存後、各時間のH₂O₂濃度と濃度変化グラフを表示します。

- 教員は「作成した講座」一覧から講座を開き、その中で実験条件と所属クラスを設定します。配布するのは講座リンクだけです。
- 講座名の編集と、講座・所属クラス・保存記録をまとめた削除にも対応します。
- 生徒はクラスを選び、班名を自由に入力。コードや生徒アカウントの入力は不要です。
- 同じクラスの各端末の記録を分けて保存し、互いの記録を上書き・読み出ししません。
- 教員はメール・パスワードでログインし、クラス・班名別の集約、保存履歴、速度定数解析、CSV出力と個別削除ができます。
- 実験結果の班名から、入力表・酸素累積量・H₂O₂濃度・平均濃度対平均速度の回帰グラフを開けます。
- 講座内のクラス数・クラス内の班数に固定の上限はありません。
- 講座リンクは一覧・設定画面に常時表示し、横のコピーボタンでコピーできます。
- クラスはドラッグまたは上へ・下へで並べ替え、生徒のクラス選択にも同じ順序を反映します。

## 公開先

- 教員用：https://easy-person.github.io/peroxide-reaction-lab/admin.html
- 生徒用：教員画面で作成した講座リンクを配布します。

GitHub Pagesが画面を、Supabaseが保存・計算・教員認証を担当します。`main` への変更はGitHub Actionsで自動公開します。詳しい操作と初期設定は [SETUP.md](SETUP.md) を参照してください。

## 確認

Node.js 22以降で実行します。

```sh
npm ci
npm test
```

SQLテストはPGlite（PostgreSQL）を使い、計算・アクセス制御・班の記録分離を確認します。JSDOMで入力・保存・表示を確認します。Supabase実環境での接続確認とは別です。
